# Лендинг автоматизации бизнеса

Адаптивная одностраничная страница об автоматизации процессов, настройке CRM
и внедрении информационных систем. Визуальная основа — тёмные шоколадные
оттенки и тёплые золотистые акценты.

- `index.html` — шапка, описание услуг, подход к работе и подвал страницы
- `css/styles.css` — оформление и адаптивные состояния
- `js/main.js` — автоматическая подстановка текущего года
- `assets/` — изображения, шрифты и другие ресурсы

Откройте `index.html` в браузере, чтобы посмотреть страницу. Сборка и
установка зависимостей не требуются.
